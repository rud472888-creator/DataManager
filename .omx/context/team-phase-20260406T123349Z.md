## Task statement

Run a 4-lane executor team to extend the approved A1/A2 Footage Data Manager implementation without reopening architecture. The lanes are:

1. runtime verification / checksum / recovery hardening
2. parser / metadata integration
3. report generation pipeline
4. remote console UX + tests/docs

## Desired outcome

- `VERIFYING` becomes a real runtime stage with durable file/job verification state
- metadata parsing is integrated or honestly capability-gated
- report pipeline generates real artifacts for implemented report types
- remote console monitors the expanded pipeline and accesses reports
- runtime/web boundary stays intact

## Constraints

- Runtime authority remains local-only; browser never gets filesystem authority.
- REST + WebSocket remain the only remote interaction surfaces.
- Single active offload job remains hard.
- `app/runtime` core stays under a single owner lane during this team phase.
- Shared contract changes must be explicit and documented.
- Native iOS and local full-feature UI are out of scope.
- No fake completeness; partial implementations must stay explicit.
